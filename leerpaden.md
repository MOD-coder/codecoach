# Leerpaden software development

Deze leerpaden geven een weekstructuur voor zelfstudie. CodeCoach gebruikt ze om een persoonlijk studieplan op te stellen. Elke week: 1 concept, 1 oefening, 1 mini-project-stap, 1 reflectievraag.


## Niveau-indicatie

| Niveau | Kenmerken | Voorbeeld |
|---|---|---|
| Beginner | Geen of weinig programmeerervaring; leert syntax, variabelen, condities, loops, functies | Eerste jaar mbo-4 / hbo propedeuse |
| Gemiddeld | Kan kleine programma's schrijven; leert OOP, datastructuren, bestanden, API's, Git, testen | Tweede jaar |
| Gevorderd | Bouwt complete applicaties; leert architectuur, databases, frameworks, CI/CD, security | Derde/vierde jaar, stage |


## Leerpad A – Python voor beginners (6 weken)

| Week | Onderwerp | Oefening | Mini-project-stap |
|---|---|---|---|
| 1 | Variabelen, datatypes, input/output, rekenen | Rekenmachine op de commandline | Kies je project (bijv. boodschappenlijst-app) |
| 2 | Condities (if/elif/else), booleaanse logica | Leeftijdscheck met meerdere regels | Menu met keuzes |
| 3 | Loops (for/while), range, break/continue | Tafel van vermenigvuldiging; getallen raden | Herhalend menu |
| 4 | Lists, dictionaries, strings | Woordenteller; top-3 uit een lijst | Items toevoegen/verwijderen |
| 5 | Functies, parameters, return, scope | Herschrijf week 1–4 met functies | Code opdelen in functies |
| 6 | Bestanden lezen/schrijven, foutafhandeling (try/except) | Opslaan en laden van een lijst | Data bewaren; presenteer je project |

Bronnen: docs.python.org/3/tutorial, Microsoft Learn 'Python voor beginners', W3Schools Python.


## Leerpad B – Webdevelopment basis: HTML, CSS, JavaScript (8 weken)

| Week | Onderwerp | Oefening |
|---|---|---|
| 1 | HTML-structuur, semantische elementen, formulieren | Persoonlijke pagina met sections |
| 2 | CSS: selectors, box model, kleuren, typografie | Pagina opmaken |
| 3 | CSS layout: Flexbox en Grid, responsive design | Responsive portfolio-layout |
| 4 | JavaScript basis: variabelen, functies, arrays, objecten | Interactieve to-do lijst (in memory) |

| 6 | Fetch API en JSON, async/await | Weer- of quote-app met een openbare API |
| 7 | Modules, foutafhandeling, localStorage | To-do lijst bewaren |
| 8 | Toegankelijkheid, performance-basis, publiceren (GitHub Pages) | Portfolio online zetten |

Bronnen: developer.mozilla.org/docs/Learn, Microsoft Learn 'Web Development for Beginners'.


## Leerpad C – Objectgeoriënteerd programmeren in Java of C# (6 weken)

| Week | Onderwerp | Oefening |
|---|---|---|
| 1 | Klassen, objecten, velden, constructors | Klasse Student met naam en cijfers |
| 2 | Encapsulatie, properties/getters-setters, methoden | Bankrekening met saldo-controle |
| 3 | Collections (List, Dictionary/Map), iteratie | Klassenlijst beheren |

## Leerpad D – Databases en SQL (5 weken)

| Week | Onderwerp | Oefening |
|---|---|---|
| 1 | Relationeel model, tabellen, primaire/vreemde sleutels, ERD | ERD voor een bibliotheek |
| 2 | SELECT, WHERE, ORDER BY, LIMIT, functies | Zoekvragen op een voorbeelddatabase |
| 3 | JOINs (INNER, LEFT), GROUP BY, HAVING | Rapportages per categorie |
| 4 | INSERT/UPDATE/DELETE, transacties, constraints | Data invoeren en corrigeren |
| 5 | Normalisatie (1NF–3NF), indexen, koppeling vanuit code (parameterized queries) | Database koppelen aan je app zonder SQL-injectie |


## Leerpad E – Professioneel ontwikkelen (gevorderd, 6 weken)

- Week 1: Git-workflow in teams, pull requests, code review
- Week 2: Clean code, refactoring, design patterns (Factory, Strategy, Observer)
- Week 3: REST API's ontwerpen en bouwen (FastAPI / ASP.NET / Express)
- Week 4: Testen: unit, integratie, test-driven development
- Week 5: CI/CD basis met GitHub Actions; containers-intro
- Week 6: Security basis (OWASP Top 10), logging, documentatie, presentatie


## Hoe CodeCoach een studieplan maakt

1. Vraag niveau, taal, beschikbare uren per week en de deadline.
2. Kies het passende leerpad en pas het tempo aan (bijv. 2 weken per rij bij 3 uur/week).
3. Voeg per week 1 concrete oefening uit de Oefenopgaven-bank toe.
4. Plan aan het eind van elke week een korte zelftoets (5 vragen) en een reflectie.
5. Herinner de student om het werk in Git bij te houden.
