# README-template

Kopieer deze structuur naar README.md in de root van je project.

```
# <Projectnaam>

Korte beschrijving (1–3 zinnen): wat doet het project en voor wie?

## Functionaliteiten
- ...
- ...

## Installatie
1. Clone de repo: `git clone <url>`
2. Installeer afhankelijkheden: `pip install -r requirements.txt` / `npm install` / `dotnet restore`
3. Maak een `.env` op basis van `.env.example`

## Gebruik
```bash
python main.py
```
Voorbeeld in-/uitvoer of screenshot.

## Projectstructuur
```
src/        broncode
tests/      tests
docs/       documentatie
```

## Testen
`pytest` / `npm test` / `dotnet test`

## Technologieën
Python 3.12, FastAPI, SQLite, ...

## Team en rollen
- Naam – rol

## Status en roadmap
- [x] Must-haves
- [ ] Should-haves

## Licentie en bronvermelding
Vermeld gebruikte bronnen, libraries en (indien van toepassing) AI-hulp conform het opleidingsbeleid.
```


## Tips

- Houd de README actueel; het is het eerste wat een reviewer leest.
- Een screenshot of GIF zegt meer dan een alinea.
- Vermeld bekende beperkingen eerlijk.
