# Begrippenlijst software development

| Begrip | Uitleg in gewone taal | Voorbeeld/analogie |
|---|---|---|
| Algoritme | Stappenplan om een probleem op te lossen | Een recept |
| Variabele | Naam voor een opslagplek met een waarde | Een gelabeld doosje |
| Datatype | Soort waarde: getal, tekst, waar/onwaar, lijst | int, str, bool, list |
| Functie / methode | Herbruikbaar blok code met een naam, invoer en uitvoer | Een apparaat: stop iets erin, krijg iets terug |
| Parameter / argument | Invoer die je aan een functie geeft | bereken_btw(bedrag) |
| Return | De uitkomst die een functie teruggeeft | return totaal |
| Conditie (if) | Keuze maken op basis van een voorwaarde | Als het regent, neem een paraplu |
| Loop (for/while) | Iets herhalen | Voor elk item in het winkelwagentje |
| Lijst / array | Geordende verzameling waarden | Boodschappenlijst |
| Dictionary / map | Sleutel-waarde-paren | Woordenboek: woord → betekenis |
| Klasse | Blauwdruk voor objecten met eigenschappen en gedrag | Bouwtekening van een huis |
| Object / instantie | Een concreet exemplaar van een klasse | Het huis dat is gebouwd |
| Encapsulatie | Interne details verbergen achter een nette interface | Autobediening: pedaal, geen motoronderdelen |
| Overerving | Klasse bouwt voort op een andere klasse | Hond erft van Dier |
| Polymorfisme | Zelfde aanroep, ander gedrag per type | spreek(): hond blaft, kat miauwt |
| Interface | Afspraak over welke methoden een klasse heeft | Stopcontact: past op elk apparaat met stekker |
| Recursie | Functie die zichzelf aanroept met een kleiner probleem | Matroesjka-poppen |
| Exception | Fout tijdens uitvoering die je kunt afvangen | Rookmelder |
| API | Afspraak om met een ander programma te praten | Menukaart bij een restaurant |
| REST | Stijl voor web-API's met GET/POST/PUT/DELETE | GET /studenten/12 |
| JSON | Tekstformaat voor data-uitwisseling | {"naam": "Sam", "cijfer": 8} |
| Database | Gestructureerde opslag van data | Digitale archiefkast |
| SQL | Taal om databases te bevragen | SELECT naam FROM studenten |
| Primaire sleutel | Unieke identificatie van een rij | Studentnummer |
| Vreemde sleutel | Verwijzing naar een rij in een andere tabel | klas_id in tabel studenten |
| Framework | Kant-en-klare structuur waarop je bouwt | Django, ASP.NET, React |
| Library | Verzameling herbruikbare functies | requests, NumPy |
| Compiler / interpreter | Vertaalt code naar iets dat de computer uitvoert | Java compileert; Python interpreteert |
| IDE | Programma om code te schrijven en te debuggen | VS Code, Visual Studio, IntelliJ |
| Versiebeheer (Git) | Bijhouden van wijzigingen in code | Track changes voor code |
| Repository | Projectmap met geschiedenis | Op GitHub |
| Branch | Aparte werklijn in Git | Zijweg die later weer aansluit |
| Pull request | Verzoek om code te reviewen en samen te voegen |  |
| Unit test | Automatische test van één functie |  |
| TDD | Test-driven development: eerst test, dan code |  |
| CI/CD | Automatisch testen en uitrollen bij elke wijziging | GitHub Actions |
| Debuggen | Fouten opsporen en oplossen | Detectivewerk |
| Refactoring | Code verbeteren zonder gedrag te veranderen | Opruimen |
| Big-O | Hoe de looptijd groeit met de invoer | O(n), O(n²), O(log n) |
| Front-end / back-end | Wat de gebruiker ziet / wat op de server gebeurt | Restaurant: zaal / keuken |
| Framework vs. library | Framework roept jouw code aan; jij roept een library aan |  |
| Agile / Scrum | Iteratief werken in korte sprints | Sprint van 2 weken |
| User story | Wens van een gebruiker in één zin | Als ... wil ik ... zodat ... |
| MVP | Minimale werkende versie met de kern | Eerst een fiets, dan een auto |
| OWASP Top 10 | Lijst van de 10 grootste webbeveiligingsrisico's | Injectie, XSS, ... |
| Hashing | Onomkeerbare 'vingerafdruk' van data | Wachtwoorden opslaan |
| Environment variable | Instelling buiten de code (bijv. wachtwoord) | .env-bestand |
